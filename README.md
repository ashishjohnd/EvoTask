## ✨ Features

- **Tasks**: Priorities, categories, due dates, filters, search
- **Focus Timer**: Pomodoro intervals, task linking, history
- **Notes**: Editor, grid/list view, image attachments
- **Image Viewer**: Native aspect ratio preservation, scale presets, pinch-to-zoom
- **Progress**: Unified progress card & statistics
- **Customization**: Reorder dashboard sections, Material 3 themes & accents
- **Offline & Private**: Local storage only, zero network requests

## 📲 Installation

### Android
1. Download [**`EvoTask-v1.1.0.apk`**](https://github.com/ashishjohnd/EvoTask/releases/download/v1.1.0/EvoTask-v1.1.0.apk)
2. Open and tap **Install**

### Waydroid (Linux)
```bash
adb connect 192.168.240.112:5555
adb install -r EvoTask-v1.1.0.apk
adb shell am start -n com.evo.evotasks/.MainActivity
waydroid show-full-ui
```
