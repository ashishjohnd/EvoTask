## ✨ Features

- **✅ Smart Tasks**: Create, prioritize, categorize, and set due dates with overdue alerts.
- **📝 Simple Notes**: Quick notes with instant search and clean read/edit modes.
- **📊 Visual Progress**: Progress bar and charts to track your daily productivity.
- **🔒 100% Offline & Private**: No accounts, no internet required, no tracking. All data stays on your phone.
- **🌓 Dark & Light Modes**: Beautiful Material theme with auto system switching.
- **↩️ Undo Delete**: Instant undo button so you never lose tasks or notes by mistake.
- **⚡ Lightweight**: Just 28 MB, instant launch, and smooth 60fps scrolling.

## 📲 How to Install

### On Android Phones
1. Download **[`EvoTask-v1.0.1-arm64.apk`](https://github.com/ashishjohnd/EvoTask/releases/download/v1.0.1/EvoTask-v1.0.1-arm64.apk)** (28 MB).
2. Tap the file in your Downloads to install.
3. If asked, allow "Install from unknown sources".

### On Waydroid (Linux)
```bash
adb connect 192.168.240.112:5555  # your Waydroid IP
adb install -r EvoTask-v1.0.1.apk
adb shell am start -n com.evo.evotasks/.MainActivity
```
